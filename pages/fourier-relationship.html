ラプラス変換とフーリエ変換の関係

ラプラス変換とフーリエ変換は、どちらも信号解析や制御工学で重要な変換です。本ページでは、これら2つの変換の定義、違い、そして関係性について解説します。

1. フーリエ変換の定義

1.1 フーリエ変換（Fourier Transform）

関数 f(t) のフーリエ変換は以下のように定義されます：

$$F(\omega) = \mathcal{F}\{f(t)\} = \int_{-\infty}^{\infty} e^{-j\omega t} f(t) \, dt$$

ここで：

  • ω：角周波数（実数）
  • j：虚数単位（j² = -1）
  • F(ω)：周波数領域での表現

1.2 逆フーリエ変換

$$f(t) = \mathcal{F}^{-1}\{F(\omega)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{j\omega t} F(\omega) \, d\omega$$

2. ラプラス変換の定義（復習）

関数 f(t) のラプラス変換は：

$$F(s) = \mathcal{L}\{f(t)\} = \int_0^{\infty} e^{-st} f(t) \, dt$$

ここで：

  • s：複素変数（s = σ + jω）
  • σ：実部（減衰係数）
  • ω：虚部（角周波数）

3. ラプラス変換とフーリエ変換の違い

項目 ラプラス変換 フーリエ変換
変数 複素変数 s = σ + jω 実変数 ω（角周波数）
積分範囲 0 から ∞ -∞ から ∞
適用範囲 因果信号（t ≥ 0） 非因果信号を含む
収束条件 Re(s) > σ₀ が必要 絶対積分可能性
安定性判定 極の位置で判定 周波数応答で判定
初期条件 自動的に組み込める 別途処理が必要

4. 数学的関係

4.1 ラプラス変換からフーリエ変換へ

ラプラス変換において、s = jω と置き換えると（σ = 0）、フーリエ変換が得られます：

$$\mathcal{L}\{f(t)\}\big|_{s=j\omega} = \int_0^{\infty} e^{-j\omega t} f(t) \, dt$$

ただし、これは因果信号（t ≥ 0）の片側フーリエ変換に相当します。

4.2 条件付きの等価性

因果信号 f(t)（t < 0 で f(t) = 0）に対して、ラプラス変換が σ = 0 で収束する場合：

$$F(j\omega) = \mathcal{L}\{f(t)\}\big|_{s=j\omega}$$

つまり、特定の条件下では、ラプラス変換はフーリエ変換を一般化したものと言えます。

4.3 減衰の役割

ラプラス変換の実部 σ は、減衰係数として機能します。これにより：

  • 発散する信号（例：指数成長）を扱える
  • 初期条件を自然に組み込める
  • 収束性の条件が緩和される

5. 具体例による比較

5.1 例1：単位ステップ関数

関数：f(t) = u(t) = 1 (t ≥ 0), 0 (t < 0)

ラプラス変換

$$\mathcal{L}\{u(t)\} = \frac{1}{s} \quad (s > 0)$$

s = jω を代入すると：

$$\frac{1}{j\omega}$$

フーリエ変換

単位ステップ関数は非絶対積分可能なため、古典的なフーリエ変換が存在しません。しかし、分布関数を使用すると：

$$\mathcal{F}\{u(t)\} = \pi\delta(\omega) + \frac{1}{j\omega}$$

ここで δ(ω) はディラックのデルタ関数です。

5.2 例2：指数関数

関数：f(t) = e^(-at)u(t)（a > 0）

ラプラス変換

$$\mathcal{L}\{e^{-at}u(t)\} = \frac{1}{s + a} \quad (s > -a)$$

s = jω を代入：

$$\frac{1}{a + j\omega}$$

フーリエ変換

$$\mathcal{F}\{e^{-at}u(t)\} = \frac{1}{a + j\omega}$$

注目：この場合、ラプラス変換（s = jωで評価）とフーリエ変換が完全に一致します！

5.3 例3：三角関数

関数：f(t) = sin(ω₀t)u(t)

ラプラス変換

$$\mathcal{L}\{\sin(\omega_0 t)u(t)\} = \frac{\omega_0}{s^2 + \omega_0^2}$$

s = jω を代入：

$$\frac{\omega_0}{(j\omega)^2 + \omega_0^2} = \frac{\omega_0}{\omega_0^2 - \omega^2}$$

フーリエ変換

分布関数を使用：

$$\mathcal{F}\{\sin(\omega_0 t)\} = \pi j[\delta(\omega - \omega_0) - \delta(\omega + \omega_0)]$$

6. 周波数応答との関係

6.1 システムの周波数応答

システムの伝達関数 G(s) に対して：

  • ラプラス領域の伝達関数：G(s)
  • 周波数応答（フーリエ領域）：G(jω) = G(s)|_{s=jω}

6.2 ボード線図

システムの周波数応答 G(jω) は、ボード線図で表現されます：

  • ゲイン：|G(jω)| [dB]
  • 位相：∠G(jω) [度]

6.3 例：1次遅れシステム

伝達関数：

$$G(s) = \frac{1}{\tau s + 1}$$

周波数応答：

$$G(j\omega) = \frac{1}{1 + j\omega\tau}$$

ゲイン：

$$|G(j\omega)| = \frac{1}{\sqrt{1 + (\omega\tau)^2}}$$

位相：

$$\angle G(j\omega) = -\arctan(\omega\tau)$$

7. 実務での使い分け

7.1 ラプラス変換を使う場合

  • 微分方程式を解きたい
    初期条件を自動的に組み込める
  • 線形システムを設計したい
    ナイキスト線図、ニコルス線図などで安定性を判定
  • 因果信号を扱う
    t ≥ 0 の信号に最適
  • 発散する信号を扱う
    減衰係数σで発散を補正

7.2 フーリエ変換を使う場合

  • 周波数成分を分析したい
    音声・画像処理
  • 定常状態の周波数特性を知りたい
    周波数応答解析
  • 非因果信号を扱う
    過去と未来の両方を含む信号
  • スペクトル密度を計算したい
    パワースペクトル解析

7.3 両方を使う場合

実務では、両者を組み合わせることが多いです：

  • ラプラス変換でシステム設計と安定性解析
  • フーリエ変換で周波数応答の詳細な分析

8. 他の関連変換

8.1 Z変換

デジタル信号処理での変換。ラプラス変換の離散版と言えます：

$$X(z) = \sum_{n=0}^{\infty} x[n]z^{-n}$$

8.2 離散フーリエ変換（DFT）

デジタル信号のフーリエ変換。FFT（高速フーリエ変換）で高速に計算可能：

$$X[k] = \sum_{n=0}^{N-1} x[n]e^{-j2\pi kn/N}$$

8.3 変換の関係図

ラプラス変換（連続・因果・複素周波数）

↓ (s = jω) ↓

フーリエ変換（連続・全範囲・実周波数）

↓ (サンプリング) ↓

離散フーリエ変換（離散・全範囲・実周波数）

← (z変換) →

Z変換（離散・因果・複素周波数）

9. まとめ

重要なポイント

  • ラプラス変換は複素周波数領域での変換で、因果信号と初期条件を自然に扱える
  • フーリエ変換は実周波数領域での変換で、周波数成分の分析に優れている
  • 特定の条件下では、ラプラス変換は s = jω でフーリエ変換に帰着する
  • 実務では、制御工学ではラプラス変換、信号処理ではフーリエ変換をよく使う
  • 両者は補完的な関係にあり、問題に応じて使い分けることが重要
